# 📊 Customer Segmentation Analysis using K-Means Clustering

## 🚀 Project Overview

This project is a Machine Learning based Customer Segmentation System developed using the K-Means Clustering algorithm. The application analyzes customer behavior based on Annual Income and Spending Score to group customers into different segments.

The project also includes:

* 🔐 Login & Registration System
* 📈 Interactive Dashboard
* 📊 Data Visualizations using Plotly
* 🌐 Flask Web Application
* 💡 Business Insights Generation

---

# 🎯 Objectives

* Analyze customer purchasing behavior
* Group customers into meaningful segments

# 🤖 Machine Learning Model

## K-Means Clustering

The K-Means algorithm is used to segment customers based on:

* Annual Income
* Spending Score

### Cluster Categories:

* 💎 High Value Customers
* 📉 Low Value Customers
* 🎯 Target Customers
* 🛍️ Impulsive Buyers
* ⚖️ Average Customers
